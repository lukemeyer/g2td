# G2TD: Tower Defense

A tower defense game for the Even Realities G2 glasses (Even Hub app).

## How it draws

- **Image (4 tiles):** everything that only changes between waves: the map, the road, the towers, and an enemy sprite in every road cell, turned to face the way its lane runs.
- **One dim text layer:** covers every road cell with `█`, except where an enemy is. A revealed cell *is* the enemy. The road in the image is painted at the same brightness as the covers, so the covered road reads as one surface.
- **More text layers:** the thin lines of built triplines, effects and the cursor (with a layer half a row lower for lines that cross a row gap), marks cut into enemies, the HUD box, and a message line in a dark box the map draws while building.

The road is two lanes wide. Each lane holds one enemy type, and the lanes swap at a few points that are re-rolled every wave.

## How it plays

Six maps, one after another: Cargo Bay, Hab Ring, Regolith Mine, Reactor, Hydroponics, then the Boss Bot in the Airlock, where the robots got in. There is also a random map with endless waves. Each road map is 5 waves; clearing one moves on to the next with the towers gone and the lives carried over. Every 4th wave of a road map is a swarm of walkers. The boss has three arms, walkers, drones and a swarm, and turns the next living one to the road after every wave; the build phase says what is coming. Half way through each wave the boss holds back until the road is clear, and the turret at the end of the road's first straight gets two shots at the arm; each arm takes three hits, and nothing else hurts the arms. Destroying all three wins.

Every step of a wave is three frames: enemies move one cell, the towers about to fire show it, then their shots land. Each hit is cut into the enemy it lands on.

- **Triplines** (laser, stasis) sit across a straight stretch. A laser hits everything on its line, in both lanes, and fires every other step, so an enemy can slip past. Stasis slows what crosses it to a third of its speed for 7 steps, so a laser a slot or two after it hits most enemies twice.
- **Turrets** (sniper, cannon) sit past a corner, in line with one straight stretch, and fire straight down it from whichever barrel is on the target's lane. A sniper reaches 4 cells and hits one enemy; a cannon reaches 2 and splashes every road cell touching its target, diagonals included.

## Layout

| Path | What it is |
|---|---|
| `src/maps.json` | The six maps: roads, slots, waves, difficulty, the boss's arms, what each one's art shows. |
| `src/rules.ts` | Game rules, with no display code. Shared by the game and the balance simulator. |
| `src/phone.ts` | The phone page: a guide to the enemies, towers and maps, and this game's stats. |
| `src/main.ts` | Display, map image, input, and the bridge to the glasses. |
| `src/sprites.ts` | The boss, enemy and tower sprites, generated by `tools/import_sprites.py`. |
| `src/render/` | The map renderer (floors, pieces and their joins, walls, the road), shared by the game, the map editor and the art library, and the maps' layouts. |
| `src/pack.ts` | The art pack (`art/pack/`), bundled by `tools/pack_build.py`. |
| `src/png.ts` | 4-bit greyscale PNG encoder for image tiles. |
| `tools/balance.ts` | Headless balance check that plays the real rules with several build strategies on every map. |
| `src/random_map.ts` | The random map: a road, its slots and its difficulty from a seed. |
| `tools/import_sprites.py` | Convert the enemy and tower art in `art/sprites/` to `src/sprites.ts`. |
| `art/` | The art pack (`pack/`), each map's layout (`maps/<id>/layout.json`), the game sprites' picked art (`sprites/`), and the house-style reference (`reference/couch-s1.png`). |

## Commands

```bash
npm install
npm run dev          # dev server on :5173
npm run simulate     # Even Hub simulator against the dev server
npm run play         # browser playtest on :5174/play.html, with buttons and keys for the glasses' input
npm run balance      # balance table
npm run check        # type check, build, balance, pack
npm run pack         # build and write g2td.ehpk
npx evenhub upload g2td.ehpk -m "what changed"   # private build on the hub (bump version in app.json and package.json first)
```

To rebuild the art pack or the sprites (needs Python with Pillow, e.g. in a venv):

```bash
python3 -m venv .venv && .venv/bin/pip install pillow
.venv/bin/python -I tools/pack_build.py
.venv/bin/python -I tools/import_sprites.py
```

How the art is made (the house style, the sketches, generating pieces with a local image model) is in [docs/art.md](docs/art.md). The phone guide's text is in [docs/guide.md](docs/guide.md) and every message line in [docs/messages.md](docs/messages.md).

## Controls

- **Swipe:** move along the free slots in the order they stand along the road (up goes the way the enemies walk), then Start Wave. Built slots are skipped. The list wraps.
- **Tap:** pick a slot, then swipe through its tower types and tap to confirm. Building happens between waves. A tower can't be sold, but one built since the last wave can be removed for a full refund until the next wave starts.
- **Double tap:** exit (the glasses' own exit dialog asks first; an open choice is dropped).
- **Saving:** the game is saved after every wave and every build, and resumed on launch; a wave cut short (the app closed, the connection lost) starts again.
- **Long press:** opens the menu: Start Wave, Fast Mode (4x instead of the normal 2x), Choose map (jump straight to any map), Restart (this map or all maps; it asks first).

## Map editor (dev only)

With `npm run dev` running, open http://localhost:5173/tools/map-editor/ to place and turn pieces on a map's cells, paint its floor and draw walls; Save writes `art/maps/<id>/layout.json` and the game reloads with it. http://localhost:5173/tools/art-library/ shows every picture in the art pack as the game draws it, for review. Neither is part of the built app.
